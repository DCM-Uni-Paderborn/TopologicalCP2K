## Scope of the independent reference

The input fixture is the existing convention-aware `irreptables==3.1.0`
fixture described in `character-reference-validation.md`. It reads data
from the package, not IrRep's character-generation implementation. Source
file hashes and the Bloch/Cartesian convention adapter are retained with
that report. The present test uses only Gamma records, removes the space-group
translations and realizes the remaining point group as an onsite group.
There are 230 space groups times two spin choices, but these are not 460
distinct crystallographic point groups or all real Wyckoff-site stabilizers.
The finite-precision reference spin lifts and complete characters are retained.

Three variants apply cell scales 1e-100, 1 and 1e100; the second and third
include a unimodular shear, origin shift, reversed operation list and integer
coset changes, and the third also rotates the Cartesian axes. The new
`atomic_band_site_match` kernel retains the actual native spin lifts and takes
an explicit reference-to-native Cartesian orientation. Unitary spin matrices
use V U V-dagger; antiunitary matrix parts use V A V-transpose, with A including
i sigma_y. Overlap with the actual native lifts fixes one phase per operation.
No representation-dependent phase is fitted and no equal-dimension heuristic
is used. The existing matcher independently verifies the full operation
product/factor map, complete characters and central projectors.

## Analytic tests

- C3 scalar/spinful ordinary and grey variants distinguish equal-dimensional
  complex characters, paired restrictions and doubled restrictions.
- Axis rotation, improper orientation, basis shear, shifted origin, operation
  reordering and consistent complex rephasing preserve reference labels.
- Incorrect phases/characters, a missing antiunitary J=i sigma_y, duplicate
  operations, wrong axes, nonfinite/huge values and an unconstructed band
  are rejected. No physical reference value was changed.
- P6_3 has two sites and a C3 onsite subgroup. Scalar/spinful ordinary/grey
  variants are checked after simultaneous axes/basis/origin/order changes.
  At k_z=0,1/4,1/2, site-exchanging operations have zero trace; stabilizing
  operations agree with the analytic two-site sum, screw phase and explicit
  reference-to-native spin convention.
- A magnetic C2*T onsite stabilizer with spinful square +1 is distinguished
  from an antiunitary half translation exchanging two sites, for both
  scalar and spinful bands.

These tests exercise an actual nonsymmorphic site example and magnetic
algebra, not a complete nonsymmorphic/magnetic materials catalogue. No
runtime reference database or new input keyword is introduced. Standard
onsite/EBR labels are not automatically assigned to Gaussian bands. Complete
actual-site EBR identities and global connectivity remain separate work.

## Builds and reproduction

Optimized serial and two-rank MPI binaries use the local GNU Fortran/OpenBLAS
builds. The focused instrumented executable recompiles symmetry,
little-group, corepresentation, character-matching and band-representation
modules and the test with bounds checks, floating-point traps and undefined
behavior instrumentation. See `build_onsite_instrumented.sh` for exact flags.
It omits its SPGLIB database test interface but links the existing CP2K release
library. This is not a completely instrumented Gaussian/MPI build or an
independent no-SPGLIB CP2K build. The full build logs retain compiler warnings
in unchanged dependencies; no warning suppression was added.

The compressed archive `onsite-reference-records.tar.gz` contains the exact
fixture, complete serial/MPI/instrumented character output, final driver and
build logs, formatting results and the changed source/documentation files.
Paths are relative to the CP2K source root. Member SHA-256 hashes are in
`onsite-reference-files.sha256`. After extracting the archive in a scratch
directory, its numerical comparison can be rerun without CP2K:

```sh
shasum -a 256 -c /path/to/onsite-reference-files.sha256
python3 /path/to/verify_onsite_outputs.py \
  build-serial/onsite-reference-external.log \
  build-mpi/onsite-reference-external.log \
  build-serial/onsite-reference-debug.log
```

To rerun the CP2K calculations, use the recorded research source and builds:

```sh
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 build-serial/bin/topology_band_unittest.ssmp \
  --site-reference=build-serial/character-convention-reference.dat
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 mpiexec --tag-output -n 2 \
  build-mpi/bin/topology_band_unittest.psmp \
  --site-reference=build-serial/character-convention-reference.dat
bash build_onsite_instrumented.sh
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 build-serial/onsite-debug/onsite-reference \
  --site-reference=build-serial/character-convention-reference.dat
```

The official final driver selection is
`UNIT/topology_(integer|atomic|wyckoff|band|reciprocal|site|character|symmetry)_unittest|QS/regtest-little-group|QS/regtest-topology$|QS/regtest-kp-1$`.
Serial uses one rank, two threads and three concurrent tasks; MPI uses two
ranks, two threads and two concurrent tasks. Both use OPENBLAS_NUM_THREADS=1,
OMP_STACKSIZE=128M and the validated thread-safe OpenBLAS insertion library
recorded in the logs. Each passes 179 assertions with zero failed or wrong
tests. `./make_pretty.sh --no-cache` passes all three changed CP2K files.

All external programs, local reference sweeps and final official drivers
finished successfully; this report does not infer success from partial output.
