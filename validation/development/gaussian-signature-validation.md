# Gaussian-band atomic signature comparison

Verified 24 September 2026. Builds on `integer-signature-validation.md` and
`atomic-signature-validation.md`. The CP2K research change is committed locally;
no upstream implementation publication is implied by this manuscript record.

## Physical integration

`ATOMIC_SIGNATURES T` in DFT/PRINT/WANNIER90 implies LITTLE_GROUP_IRREPS and
uses explicit NNKP, WILSON or TRIM points. The selected Gaussian-band frames
first pass existing metric, subspace, Hamiltonian and projective-product
checks, and separation from computed excluded bands at every sampled point.
SOC is post-SCF GTH; time reversal requires a restricted SCF. The method does
not prove isolation between sampled points or assume an occupied prefix.

Atomic reference operations are matched bijectively to the band operations,
including antiunitary flags and integer coset translations. These translations
induce explicit Bloch character phases. The complete product/factor mapping,
with conjugation on antiunitary products, is checked before decomposing into
the reference row basis. Standard labels or arbitrary irrep order are not used
as matching keys. Cell, spin, operation or rank inconsistencies are rejected.

The output gives separate signed and nonnegative membership, with values
1 (yes), 0 (proven no for the supplied matrix), -1 (unresolved). A node budget
is mandatory internally and defaults to one million through
ATOMIC_SIGNATURE_MAX_NODES. Arithmetic/search limits do not become topology
claims. Reference-construction memory limits stop the analysis; invalid data
or failed witness verification abort. All tests remain on the supplied
reciprocal sample, with full conventional-cell translation sectors.

## Physical fixtures

Both serial and two-rank MPI focused drivers pass 73/73 checks: four native
unit programs and 69 Gaussian-directory assertions. Existing physical
reference values are unchanged. The existing cases now also assert integer
signature outcomes:

- Scalar Ne at Gamma and Ne/SOC at Gamma and a generic PT-symmetric point:
  signed and nonnegative membership.
- Centered and sheared He; complete He/GPW, He/GAPW and Ne/SOC screw branches:
  signed and nonnegative membership.
- One selected He screw branch: neither signed nor nonnegative membership,
  consistent with its independently detected reciprocal-loop monodromy.
- Refined Wilson case: membership on both the four- and twelve-point sets.
- New orthorhombic He TRIM fixture: signed membership; zero-node nonnegative
  search explicitly unresolved. Its GPW basis/potential use UZH MOLOPT/GTH.

The new budget fixture initially used a cubic cell; all scientific checks
passed but its detailed output exceeded the driver's output-size limit.
An orthorhombic cell reduces irrelevant symmetry-table volume for this budget
test. The final fixture passes without output suppressions or relaxed
thresholds. The cubic Gamma/SOC tests remain separate.

## Mapping and exported-certificate checks

The native matrix driver tests all 2,120 ordinary/grey and scalar/spinful
catalogues over 530 Hall settings. It recovers the same band signature after
operation permutations, irrep-column permutations and integer coset shifts.
The changed factors are independently regenerated by the little-group
constructor, not assigned using the formula being tested. Corrupted factors
and unmatched operations are rejected. Complete serial, two-rank MPI and
bounds/undefined-behavior-instrumented mapping-kernel runs pass. The other
CP2K modules in the debug run remain linked from the existing library.

`check_atomic_witnesses.py` is an independent, exact-integer reader of the
exported .little_group records. For each of the serial and MPI runs it checks
11 matrices and 19 witnesses, all entries and target rows, nonnegative
coefficients where required, and target/column band ranks at every k block.
Every exported witness satisfies A*x=b exactly using Python's arbitrary-size
integers. This checks output integrity, not independent classification of
the negative cases. The script is validation-only, not a CP2K dependency.

thread and OMP_STACKSIZE=128M on local Apple ARM with GNU Fortran 16.1.0.
`make_pretty.sh` passes and is idempotent on the tested source.

## Boundaries

This is now an actual Gaussian-band diagnostic, not merely construction of
model reference columns. It is still not a complete general TQC classifier:
reciprocal-stratum coverage/connectivity, conventional-to-primitive matching,
elementarity/equivalence, standard labels and larger converged material
validation remain distinct tasks. No positive sampled signature establishes
Bloch-bundle triviality, and a negative signature alone does not distinguish
a symmetry-enforced gap obstruction from a gapped topological band set.
