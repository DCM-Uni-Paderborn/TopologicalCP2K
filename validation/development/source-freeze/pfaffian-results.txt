Independent numerical tests

The 600-query synthetic suite resolves all 468 nonsingular queries and rejects
all 132 singular queries. The 636-query stress suite resolves all 336 nonsingular
queries and rejects all 300 singular queries. Each fixture, scale and expected
sign is checked individually, not only the aggregate counts. There are no wrong
accepted signs. All 930 one-sided-roundoff perturbations of the 32-site chain
resolve with the expected positive sign. The maximum solve residual is
4.79176328310641e-16 for that roundoff sweep.

An additional 63 native C ABI checks cover invalid dimensions, coordinates,
tolerances, nonfinite/overflowing matrix entries, additive coordinates, singular
matrices, permutation signs, scaling, memory limits and physical-TR structure
checks for the Z2 interface. A connected Pfaffian-three fixture requests 4,400
bytes of tracked numerical workspace. That exact budget passes; one byte less
is rejected with status -6 and zero output sign. A small tolerated TR defect is
accepted at a safely positive gap and rejected when the supplied gap becomes
too small to certify its removal. These are native C tests, not MPI-wrapper tests.

All ten archived stanene export sets are replayed, including 18x18 DZVP and
12x12 TZVP meshes. All 33 queries reproduce the stored index and gap values.
The largest absolute gap difference is zero for these runs. Each query uses
one original external ordering. Maximum factor and eigen residuals are
2.056248991472289e-11 and 3.030975173539199e-11, respectively. Three small-mesh
queries also pass independent dense sign and gap checks; their largest dense
gap difference is 1.6653345369377348e-15.

Reproduction boundaries

The material replay uses the unchanged archived complete-band topology and
overlap exports. It does not rerun SCF or establish new material convergence.
Its gaps are near-zero Ritz estimates checked by residuals, not independently
certified MUMPS inertia brackets. A local factor residual is not a rigorous
global error bound. The tracked numerical-buffer cap excludes sparse input,
symbolic ordering, dependency storage and whole-process memory. Timings are
not controlled scaling benchmarks. Pfaffian factors remain local to one rank.

The separate localizer-frozen-mpi directory contains the ongoing full CP2K
rebuild and integration validation. Those results are deliberately not claimed
by this standalone adapter evidence bundle.

No manuscript overwrite, reference-value change, remote push, PR creation,
repository-visibility change or new blanket license assignment was performed.
